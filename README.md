# Supermarket Sales Analysis

## Overview
A Python data analytics project based on 500 supermarket transactions.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn and Google Colab.

## Questions Answered
1. Highest-selling product
2. Best-performing branch
3. Highest-selling category
4. Most popular payment method
5. Member vs Normal average transaction value
6. Average customer rating

## Project Files
- `Supermarket_Sales_Analysis.ipynb` — Google Colab/Jupyter code
- `supermarket_sales.csv` — 500-row dataset
- `requirements.txt` — dependencies
- `Project_Report.pdf` — submission report
- `Project_Report.docx` — editable report
- `charts/` — generated analysis charts

## Results
- Highest-selling product: **Cheese** — ₹77,905.30
- Best-performing branch: **Branch A (Delhi)** — ₹89,241.24
- Highest-selling category: **Dairy** — ₹56,849.52
- Most popular payment method: **Cash** — 132 transactions
- Member average transaction: **₹483.14**
- Normal average transaction: **₹497.07**
- Average rating: **3.99/5**
